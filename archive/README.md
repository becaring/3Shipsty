# Archived development records

These reports describe the source and tests available when they were written.
They preserve measurements, failed experiments, and integration history; they
are not instructions for the current build. Start with the repository README
and development guide for current commands.

`upstream-ci/generate-builds.yml` preserves the upstream remote-control build
configuration. The network source lock verifies these original bytes as
provenance; GitHub Actions does not execute this archived workflow.
